1. SIGN IN
================================================================================

Description: The Sign In function allows employees to access the system using their registered email address and password. Upon successful authentication, users are directed to the home screen. If a user has a temporary password, they will be required to change it before accessing the system.

Instructions:

Figure 1: Sign in screen

Step 1: Launch the application
    Open the Employee Attendance Management System app on your device.

Step 2: View the Sign In screen
    The system displays the Sign In screen with:
        Application logo/icon
        "Sign in" title
        Email input field
        Password input field
        "Forgot password?" link
        "Sign in" button

Step 3: Enter your email address
    Tap on the Email field.
    Enter your registered email address.
    The system validates the email format.

Step 4: Enter your password
    Tap on the Password field.
    Enter your password.
    By default, password characters are hidden (shown as dots).
    Tap the eye icon to show/hide password characters.

Step 5: Submit login credentials
    Tap the "Sign in" button.
    The system displays a loading indicator.
    The button becomes disabled during processing.

Step 6: System processes authentication
    Case A - Successful Login (Regular Password):
        The system validates credentials.
        Success message may appear briefly.
        User is automatically redirected to the Home screen.
        User can access all system features.
    
    Case B - Successful Login (Temporary Password):
        The system validates credentials.
        System detects temporary password status.
        User is automatically redirected to Change Password screen.
        User MUST change password before accessing the system.
        See Section 3.2 for password change instructions.
    
    Case C - Failed Login:
        Error message appears at the bottom of the screen.
        Common error messages:
            "Invalid email or password" - incorrect credentials
            "Account is locked" - account has been disabled
            "Network error" - connection problem
        User remains on Sign In screen.
        User can retry with correct credentials.

Step 7: Access the system
    After successful login, user is on the Home screen.
    User can now access all available features based on their role.

2. FORGOT PASSWORD
================================================================================

Description: The Forgot Password function allows users who have forgotten their password to request a new temporary password. The system will send a new password to the user's registered email address. Users must then use this temporary password to sign in and change it to a permanent password.

Instructions:

Figure 2: Forgot password screen

Step 1: View the Forgot Password screen
    The system displays:
        Lock reset icon
        "Forgot password" title
        Instruction text: "Enter your email to receive a new password"
        Email input field
        "Send Request" button
        Back button (top-left corner)

Step 2: Enter your email address
    Tap on the Email field.
    Enter your registered email address.
    The system validates the email format in real-time.

Step 3: Submit password reset request
    Tap the "Send Request" button.
    The system displays a loading indicator.
    The button becomes disabled during processing.

Step 4: System processes the request
    Case A - Successful Request:
        The system validates the email exists in the database.
        A new temporary password is generated.
        The temporary password is sent to the registered email.
        Success message appears: "A new password has been sent to your email"
        User is automatically returned to the Sign In screen.
    
    Case B - Failed Request:
        Error message appears at the bottom of the screen.
        Common error messages:
            "Email not found" - email is not registered
            "Account is inactive" - account has been disabled
            "Network error" - connection problem
        User remains on Forgot Password screen.
        User can retry with correct email.

Step 5: Check your email
    Open your email application.
    Look for an email from the system.
    The email contains:
        Your new temporary password
        Instructions to sign in
        Reminder to change password after login

Step 6: Sign in with temporary password
    Return to the Sign In screen.
    Enter your email address.
    Enter the temporary password from the email.
    Tap "Sign in" button.
    See Section 3.2 for changing temporary password.

Step 7 (Optional): Cancel and return
    To cancel at any time, tap the Back button (top-left).
    The system returns to the Sign In screen.
    No password reset is performed.

3. CHANGE PASSWORD
================================================================================

3.1 Change Regular Password
--------------------------------------------------------------------------------

Description: The Change Password function allows users to update their current password to a new one. This is used when users want to change their password for security reasons or regular password rotation.

Instructions:

Figure 3.1: Change password screen

Step 1: View the Change Password screen
    The system displays:
        "Change Password" title in app bar
        Lock reset icon
        "Change Password" heading
        Instruction text: "Enter current password and new password"
        Current password input field
        New password input field
        Password requirements section
        "Change Password" button
        Back button (top-left corner)

Step 2: Enter current password
    Tap on the "Current Password" field.
    Enter your current password.
    By default, password is hidden (shown as dots).
    Tap the eye icon to show/hide password.

Step 3: Enter new password
    Tap on the "New Password" field.
    Enter your desired new password.
    By default, password is hidden (shown as dots).
    Tap the eye icon to show/hide password.
    
    Password Requirements (all must be met):
        Minimum 8 characters
        At least 1 uppercase letter (A-Z)
        At least 1 lowercase letter (a-z)
        At least 1 number (0-9)
        At least 1 special character (!@#$%^&*(),.?":{}|<>)

Step 4: Review password requirements
    Below the password fields, a requirements box displays:
        ✓ At least 8 characters
        ✓ At least 1 uppercase letter
        ✓ At least 1 lowercase letter
        ✓ At least 1 number
        ✓ At least 1 special character (!@#$%^&*...)
    Ensure your new password meets all requirements.

Step 5: Submit password change
    Tap the "Change Password" button.
    The system validates all fields.
    If validation passes, the button becomes disabled during processing.

Step 6: System processes password change
    Case A - Successful Change:
        The system validates the current password.
        The system validates the new password meets requirements.
        The password is updated in the database.
        Success message appears: "Password changed successfully!"
        User is returned to the Profile screen.
        User can continue using the system with the new password.
    
    Case B - Failed Change:
        Error message appears at the bottom of the screen.
        Common error messages:
            "Current password is incorrect" - wrong current password
            "New password does not meet requirements" - validation failed
            "Network error" - connection problem
        User remains on Change Password screen.
        User can correct the information and retry.

Step 7 (Optional): Cancel password change
    To cancel at any time, tap the Back button (top-left).
    The system returns to the Profile screen.
    No password change is performed.

--------------------------------------------------------------------------------

3.2 Change Temporary Password
--------------------------------------------------------------------------------

Description: The Change Temporary Password function is mandatory for users who have received a temporary password (either from initial account setup or password reset). Users MUST change their temporary password to a permanent one before they can access the system.

Instructions:

Figure 3.2: Change temporary password screen

Step 1: Automatic redirect after login
    After signing in with a temporary password.
    The system automatically detects the temporary password status.
    User is immediately redirected to the Change Password screen.
    User CANNOT access other parts of the system until password is changed.

Step 2: View the Change Temporary Password screen
    The system displays:
        "Change Temporary Password" title
        Lock reset icon
        Warning message: "You are using a temporary password"
        Instruction: "Please change to a new password to continue"
        Current password input field (for temporary password)
        New password input field
        Confirm new password input field
        Password requirements section
        "Change Password" button
        NO back button (change is mandatory)

Step 3: Enter temporary password
    Tap on the "Current Password" field.
    Enter your temporary password (from email or administrator).
    By default, password is hidden (shown as dots).
    Tap the eye icon to show/hide password.

Step 4: Enter new password
    Tap on the "New Password" field.
    Enter your desired new password.
    By default, password is hidden (shown as dots).
    Tap the eye icon to show/hide password.
    
    Password Requirements (all must be met):
        Minimum 8 characters
        At least 1 uppercase letter (A-Z)
        At least 1 lowercase letter (a-z)
        At least 1 number (0-9)
        At least 1 special character (!@#$%^&*(),.?":{}|<>)

Step 5: Confirm new password
    Tap on the "Confirm New Password" field.
    Re-enter your new password exactly as entered in Step 4.
    By default, password is hidden (shown as dots).
    Tap the eye icon to show/hide password.

Step 6: Review password requirements
    Below the password fields, a requirements box displays:
        ✓ At least 8 characters
        ✓ At least 1 uppercase letter
        ✓ At least 1 lowercase letter
        ✓ At least 1 number
        ✓ At least 1 special character (!@#$%^&*...)
    Ensure your new password meets all requirements.

Step 7: Submit password change
    Tap the "Change Password" button.
    The system validates all fields.
    If validation passes, the button becomes disabled during processing.

Step 8: System processes password change
    Case A - Successful Change:
        The system validates the temporary password.
        The system validates the new password meets requirements.
        The system validates password confirmation matches.
        The password is updated in the database.
        The temporary password flag is removed.
        Success message appears: "Password changed successfully! Please login again."
        User session is cleared for security.
        User is automatically redirected to the Sign In screen.
    
    Case B - Failed Change:
        Error message appears at the bottom of the screen.
        Common error messages:
            "Current password is incorrect" - wrong temporary password
            "Passwords do not match" - confirmation doesn't match
            "New password does not meet requirements" - validation failed
            "Network error" - connection problem
        User remains on Change Password screen.
        User can correct the information and retry.

Step 9: Sign in with new password
    After successful password change, user is on Sign In screen.
    Enter your email address.
    Enter your NEW password (not the temporary one).
    Tap "Sign in" button.
    User is now logged in with permanent password.
    User can access all system features normally.
