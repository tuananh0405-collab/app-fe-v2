1. MY ATTENDANCE MODULE OVERVIEW
================================================================================

Description: The My Attendance module allows employees to view their attendance 
history, work hours, and shift details. The screen provides a comprehensive 
overview of attendance records with filtering options by date range and status.

Key Features:
- View attendance summary statistics
- Filter attendance by date range
- Filter attendance by status
- View detailed shift information
- Pull-to-refresh for latest data
- Quick date range selection (This Week, This Month, Last 30 Days)

================================================================================
2. VIEW MY ATTENDANCE
================================================================================

2.1 Access and Navigate the Attendance Screen
--------------------------------------------------------------------------------

Description: The My Attendance screen displays your attendance records with 
filtering options and summary statistics. All features are accessible from 
this single screen.

Prerequisites:
- User must be logged into the system
- User must have attendance records in the system

[Figure 01 - My Attendance Screen]

Step 1: Access My Attendance screen
   - From the Home screen or navigation menu, tap on "My Attendance".
   - The system navigates to the My Attendance screen.
   - The system automatically loads attendance data for the current period.

Step 2: View the screen layout
   - The screen is organized into sections:
     • App bar with "My Attendance" title and back button
     • Filter section (date range, quick filters, status dropdown)
     • Summary statistics card
     • Shift history list
     • Pull-to-refresh functionality

Step 3: View attendance summary
   - At the top of the content area, a summary card displays:
   
   Working Days:
   • Format: "X/Y" (e.g., "20/22")
   • X = Days you were present
   • Y = Total working days in the period
   
   Work Hours:
   • Format: "Xh" (e.g., "160h")
   • Total hours worked in the period
   
   Late / Early:
   • Format: "X / Y" (e.g., "2 / 1")
   • X = Number of times you arrived late
   • Y = Number of times you left early
   
   Overtime:
   • Format: "Xh" (e.g., "12h")
   • Total overtime hours in the period

Step 4: Select date range
   - In the filter section, two date buttons are displayed:
   
   Start Date:
   • Shows currently selected start date (DD/MM/YYYY format)
   • Tap to open date picker
   • Select a new start date
   • Start date must be before or equal to end date
   
   End Date:
   • Shows currently selected end date (DD/MM/YYYY format)
   • Tap to open date picker
   • Select a new end date
   • End date must be after or equal to start date
   
   Date Validation:
   • If you select start date after end date, error message appears:
     "Start date must be before end date"
   • If you select end date before start date, error message appears:
     "End date must be after start date"
   • The invalid selection is rejected

Step 5: Use quick date range filters
   - Below the date buttons, three quick filter buttons are available:
   
   This Week:
   • Sets date range to current week (Monday to Sunday)
   • Tap to apply immediately
   
   This Month:
   • Sets date range to current month (1st to last day)
   • Tap to apply immediately
   
   Last 30 Days:
   • Sets date range to last 30 days from today
   • Tap to apply immediately
   
   - When you tap a quick filter:
     • Date range updates automatically
     • Summary statistics recalculate
     • Shift list refreshes with new data

Step 6: Filter by status
   - Below the quick filters, a status dropdown is displayed:
   
   Status Options:
   • All - Shows all attendance records (no filter)
   • In Progress - Shows shifts currently in progress
   • Completed - Shows completed shifts
   • On Leave - Shows shifts where you were on leave
   • Absent - Shows shifts where you were absent
   
   To filter:
   • Tap on the status dropdown
   • Select a status from the list
   • The shift list updates to show only matching records
   • To clear filter, select "All"

Step 7: View shift history
   - Below the summary card, a list of shifts is displayed:
   
   Each shift card shows:
   • Shift date (e.g., "Monday, Dec 06, 2024")
   • Status badge (color-coded):
     - In Progress: Orange
     - Completed: Green
     - On Leave: Purple
     - Absent: Red
   • Scheduled time (e.g., "08:00 - 17:00")
   • Check-in time (if checked in)
   • Check-out time (if checked out)
   • Work hours (total hours worked)
   • Overtime hours (if any)
   • Break hours (if any)
   • Late minutes (if late, shown in red)
   • Early leave minutes (if left early, shown in red)
   • Shift notes (if any)
   
   - Shifts are sorted by date (newest first)
   - Scroll down to view more shifts
   - If no shifts match the filters, message appears:
     "No shifts found for this period"

Step 8: Refresh attendance data
   - To get the latest attendance data:
     • Pull down on the shift list
     • A loading indicator appears
     • Release to trigger refresh
     • The system fetches latest data
     • Summary and shift list update
   
   - Alternatively, navigate away and back to the screen to reload data

Step 9: Handle loading and errors
   
   Case A - Data Loading:
   • A circular loading indicator appears in the center
   • Wait for data to load
   • Summary and shifts appear when ready
   
   Case B - Data Loaded Successfully:
   • Summary card displays statistics
   • Shift list shows attendance records
   • All filters are functional
   
   Case C - Error Loading Data:
   • Error icon appears in the center
   • Error message displays (e.g., "An error occurred")
   • "Retry" button is available
   • Tap "Retry" to attempt loading again
   
   Case D - No Data Available:
   • Message appears: "No data available"
   • This may occur if:
     - No attendance records exist for the selected period
     - You are a new employee with no history
     - The date range is outside your employment period

Step 10: Return to Home
   - Tap the back button (top-left) to return to Home screen.
   - Filters and date range are reset when you leave the screen.

2.2 Understanding the Interface
--------------------------------------------------------------------------------

Description: Understanding the visual elements and data presentation helps you 
effectively use the My Attendance screen.

[Figure 02 - Interface Elements]

Status Colors and Meanings:

In Progress (Orange):
- Shift is currently active
- You have checked in but not checked out
- Work is ongoing

Completed (Green):
- Shift has been completed
- You have checked in and checked out
- All work hours are recorded

On Leave (Purple):
- You were on approved leave during this shift
- No attendance is required
- Leave request was approved

Absent (Red):
- You were scheduled but did not attend
- No check-in was recorded
- May require explanation or documentation

Summary Statistics Explained:

Working Days (X/Y):
- X = Number of days you were present (checked in)
- Y = Total working days in the selected period
- Excludes weekends and holidays (depending on your schedule)
- Example: "20/22" means you worked 20 out of 22 scheduled days

Work Hours (Xh):
- Total hours you worked in the selected period
- Calculated from check-in and check-out times
- Excludes break hours
- Example: "160h" means 160 hours total

Late / Early (X / Y):
- X = Number of times you checked in after scheduled start time
- Y = Number of times you checked out before scheduled end time
- Both are counted as attendance issues
- Example: "2 / 1" means late 2 times, left early 1 time

Overtime (Xh):
- Total overtime hours worked in the selected period
- Calculated as hours worked beyond scheduled shift time
- May be compensated according to company policy
- Example: "12h" means 12 hours of overtime

Shift Card Information:

Scheduled Time:
- Your assigned work hours for the shift
- Format: "HH:MM - HH:MM" (e.g., "08:00 - 17:00")
- This is what you are expected to work

Check-in Time:
- Actual time you started work
- Only appears if you checked in
- Compare with scheduled start time to see if late

Check-out Time:
- Actual time you finished work
- Only appears if you checked out
- Compare with scheduled end time to see if early/late

Work Hours:
- Total hours worked during the shift
- Calculated as: Check-out time - Check-in time - Break hours
- Displayed in hours with one decimal (e.g., "8.5h")

Overtime Hours:
- Hours worked beyond scheduled shift time
- Only appears if overtime was worked
- Displayed in hours with one decimal (e.g., "2.0h")

Break Hours:
- Total break time taken during the shift
- Only appears if breaks were recorded
- Displayed in hours with one decimal (e.g., "1.0h")

Late Minutes:
- Minutes you were late (checked in after scheduled start)
- Displayed in red to indicate issue
- Format: "Xmin" (e.g., "15min")
- Only appears if you were late

Early Leave Minutes:
- Minutes you left early (checked out before scheduled end)
- Displayed in red to indicate issue
- Format: "Xmin" (e.g., "10min")
- Only appears if you left early

Shift Notes:
- Additional comments or notes about the shift
- May include reasons for late arrival, early leave, or other information
- Added by you or management
- Only appears if notes exist

Date Range Selection Tips:

Custom Date Range:
- Use Start Date and End Date buttons for specific periods
- Useful for monthly reports or specific time frames
- Maximum range depends on system settings

Quick Filters:
- Use for common time periods
- Faster than selecting custom dates
- "This Week" is useful for weekly reviews
- "This Month" is useful for monthly summaries
- "Last 30 Days" is useful for rolling 30-day views

Status Filter Usage:

View All Records:
- Select "All" to see complete attendance history
- Useful for overall attendance review
- Shows all statuses mixed together

View Specific Status:
- Select a specific status to focus on that type
- "Completed" - Review successfully worked shifts
- "Absent" - Check missed shifts
- "On Leave" - Verify approved leave days
- "In Progress" - See current active shifts

Notes:
• All times are displayed in 24-hour format (HH:MM).
• Hours are displayed with one decimal place (e.g., 8.5h).
• Dates are displayed in DD/MM/YYYY format.
• Summary statistics update automatically when filters change.
• Shift list updates in real-time when filters are applied.
• Pull-to-refresh ensures you have the latest data.
• Back button returns to Home screen, not previous screen.
