1. WORK SCHEDULE MODULE OVERVIEW
================================================================================

Description: The Work Schedule module allows employees to view their assigned 
work shifts in a calendar format. Users can see scheduled shifts, check-in/out 
times, overtime hours, and other shift-related information. The module provides 
a visual calendar view with detailed shift information for each day.

Key Features:
- Monthly calendar view with shift indicators
- View multiple shifts per day
- Detailed shift information including times and status
- Check-in and check-out time tracking
- Overtime and break hours display
- Late arrival and early leave tracking
- Shift notes and comments
- Pull-to-refresh functionality
- Automatic data loading for current and upcoming months

2. VIEW WORK SCHEDULE
================================================================================

2.1 Access Work Schedule Screen
--------------------------------------------------------------------------------

Description: The Work Schedule screen is the main interface for viewing your 
assigned work shifts. It displays a calendar with shift indicators and detailed 
information for selected dates.

Prerequisites:
- User must be logged into the system
- User must have access to Work Schedule feature

[Figure 01 - Work Schedule Screen]

Step 1: Access Work Schedule
   - From the Home screen or navigation menu, tap on "Work Schedule".
   - The system navigates to the Work Schedule screen.

Step 2: View the Work Schedule screen
   - The system displays:
     • "Work Schedule" title in app bar
     • Back button (top-left corner)
     • Refresh button (top-right corner)
     • Monthly calendar view
     • Selected date heading
     • Shift details section for selected date
     • Pull-to-refresh functionality

Step 3: Initial data loading
   - When the screen opens, the system automatically:
     • Loads shifts for the current month and next month
     • Selects today's date by default
     • Displays shifts for today (if any)
     • Shows a loading indicator during data fetch
   - Calendar dots appear on dates with scheduled shifts.

Notes:
• The screen loads data for 2 months by default (current + next month).
• Today's date is highlighted with a semi-transparent circle.
• Selected date is highlighted with a solid circle.
• Dots under dates indicate shifts are scheduled for those days.

2.2 View Calendar
--------------------------------------------------------------------------------

Description: The calendar section displays a monthly view with visual indicators 
for dates that have scheduled shifts. Each date can have multiple shift 
indicators (dots) showing up to 4 shifts per day.

Prerequisites:
- User is on the Work Schedule screen
- Shift data has been loaded

[Figure 02 - Calendar View]

Step 1: Understand calendar layout
   - The calendar displays:
     • Month and year in the header (e.g., "December 2024")
     • Days of the week (Monday to Sunday)
     • Date numbers for the current month
     • Navigation arrows (< >) to change months
   - The calendar starts each week on Monday.

Step 2: Identify shift indicators
   - Dates with scheduled shifts show small dots below the date number.
   - Each dot represents one shift.
   - Up to 4 dots are displayed per date (if more shifts exist, only 4 dots show).
   - Dot color: Green (indicates shift is scheduled).

Step 3: Identify special date markers
   - Today's date:
     • Highlighted with a semi-transparent colored circle
     • Helps you quickly identify the current date
   
   - Selected date:
     • Highlighted with a solid colored circle
     • Shows which date's shifts are displayed below
     • By default, today's date is selected

Step 4: Understand date states
   - Dates can have different visual states:
     • Normal: Plain date number, no background
     • Today: Semi-transparent circle background
     • Selected: Solid circle background
     • With shifts: Small green dots below the number
     • Outside current month: Not visible (hidden)

Notes:
• Calendar shows only dates within the current month.
• Dots indicate shift count (up to 4 visible).
• If a date has more than 4 shifts, only 4 dots are shown.
• Calendar automatically updates when you change months.

--------------------------------------------------------------------------------

2.3 Select Date
--------------------------------------------------------------------------------

Description: Selecting a date in the calendar updates the shift details section 
to show all shifts scheduled for that specific date.

Prerequisites:
- User is on the Work Schedule screen
- Calendar is displayed

[Figure 03 - Date Selection]

Step 1: Tap on a date
   - Tap on any date number in the calendar.
   - The date becomes highlighted with a solid circle.
   - The previous selection is deselected.

Step 2: View date change
   - The selected date heading updates to show the new date.
   - Format: "Day, Month DD, YYYY" (e.g., "Monday, Dec 06, 2024")
   - The shift details section below updates immediately.

Step 3: View shifts for selected date
   - If the date has scheduled shifts:
     • Shift cards appear in the details section
     • Each shift shows comprehensive information
     • Multiple shifts are listed vertically
   
   - If the date has no shifts:
     • An empty state message appears
     • Icon: Calendar with X mark
     • Message: "No shifts scheduled"

Notes:
• You can select any date in the current month.
• Selection persists while navigating months.
• Tapping the same date again has no effect.
• Shift details update instantly upon selection.

--------------------------------------------------------------------------------

2.4 View Shift Details
--------------------------------------------------------------------------------

Description: The shift details section displays comprehensive information about 
all shifts scheduled for the selected date. Each shift is shown in a separate 
card with status, times, and additional details.

Prerequisites:
- User has selected a date in the calendar
- The selected date has at least one scheduled shift

[Figure 04 - Shift Details]

Step 1: View shift cards
   - Each shift is displayed in a separate card.
   - Cards are stacked vertically if multiple shifts exist.
   - Each card has a white background with subtle shadow.

Step 2: View shift header
   - At the top of each card:
     • Shift name/title (e.g., "Morning Shift", "Shift #123")
     • Status badge on the right side
     • Status badge color-coded by status type

Step 3: View scheduled time
   - First row shows scheduled shift time:
     • Clock icon
     • Label: "Scheduled"
     • Time range: "HH:MM - HH:MM" (e.g., "08:00 - 17:00")

Step 4: View check-in time (if applicable)
   - If you have checked in:
     • Login icon
     • Label: "Check In"
     • Time: "HH:MM" (e.g., "08:05")
   - This row only appears if check-in has occurred.

Step 5: View check-out time (if applicable)
   - If you have checked out:
     • Logout icon
     • Label: "Check Out"
     • Time: "HH:MM" (e.g., "17:10")
   - This row only appears if check-out has occurred.

Step 6: View overtime hours (if applicable)
   - If overtime was worked:
     • Timer icon
     • Label: "Overtime"
     • Hours: "X.Xh" (e.g., "2.5h")
   - This row only appears if overtime hours > 0.

Step 7: View break hours (if applicable)
   - If breaks were taken:
     • Coffee icon
     • Label: "Break"
     • Hours: "X.Xh" (e.g., "1.0h")
   - This row only appears if break hours > 0.

Step 8: View late arrival (if applicable)
   - If you arrived late:
     • Warning icon (amber)
     • Label: "Late"
     • Minutes: "Xmin" (e.g., "15min")
     • Text color: Red (indicates issue)
   - This row only appears if late minutes > 0.

Step 9: View early leave (if applicable)
   - If you left early:
     • Warning icon (amber)
     • Label: "Early Leave"
     • Minutes: "Xmin" (e.g., "10min")
     • Text color: Red (indicates issue)
   - This row only appears if early leave minutes > 0.

Step 10: View shift notes (if applicable)
   - If notes exist for the shift:
     • Notes appear in a separate section at the bottom
     • Light gray background box
     • Note icon
     • Note text (can be multiple lines)
   - This section only appears if notes are present.

Notes:
• Not all fields appear on every shift card.
• Only relevant information is displayed.
• Times are shown in 24-hour format (HH:MM).
• Hours are shown with one decimal place (e.g., 2.5h).
• Late and early leave are highlighted in red.

3. NAVIGATE CALENDAR
================================================================================

3.1 Change Month
--------------------------------------------------------------------------------

Description: The calendar allows navigation between months to view past and 
future shifts. The system automatically loads shift data when you navigate to 
new months.

Prerequisites:
- User is on the Work Schedule screen

[Figure 05 - Month Navigation]

Step 1: Navigate to previous month
   - Tap the left arrow (<) in the calendar header.
   - The calendar updates to show the previous month.
   - Month/year in header updates (e.g., "November 2024").

Step 2: Navigate to next month
   - Tap the right arrow (>) in the calendar header.
   - The calendar updates to show the next month.
   - Month/year in header updates (e.g., "January 2025").

Step 3: Automatic data loading
   - When you navigate to a new month:
     • The system checks if data for that month is already loaded
     • If not loaded, it automatically fetches shift data
     • Loading indicator may appear briefly
     • Calendar updates with new shift indicators (dots)
   
   - The system loads data for:
     • The displayed month
     • One month before
     • One month after
   - This ensures smooth navigation without delays.

Step 4: Selected date behavior
   - When changing months:
     • Your selected date remains selected
     • If the selected date is not in the new month, selection persists
     • Shift details continue to show the selected date's shifts
   - To view shifts in the new month, tap on a date in that month.

Notes:
• You can navigate to any month between 2020 and 2030.
• Data loads automatically when needed.
• Multiple month changes may trigger multiple data loads.
• Previously loaded data is cached for faster access.

3.2 Refresh Schedule
--------------------------------------------------------------------------------

Description: The refresh function allows you to manually reload shift data to 
ensure you have the most up-to-date information. This is useful if shifts have 
been added, modified, or cancelled.

Prerequisites:
- User is on the Work Schedule screen

[Figure 06 - Refresh Options]

Step 1: Use refresh button
   - Tap the refresh icon (circular arrow) in the top-right corner.
   - The system reloads shift data for the current date range.
   - A loading indicator appears briefly.
   - Calendar updates with latest shift information.

Step 2: Use pull-to-refresh
   - Alternatively, pull down on the shift details section.
   - Drag downward from the top of the shift details area.
   - A circular loading indicator appears.
   - Release to trigger refresh.
   - The system reloads shift data.
   - Calendar and shift details update.

Step 3: View refresh results
   - After refresh completes:
     • Calendar dots update to reflect current shifts
     • Shift details update for selected date
     • Any new shifts appear
     • Cancelled shifts disappear
     • Modified shift information updates

Notes:
• Both refresh methods reload the same data.
• Use refresh if you suspect data is outdated.
• Refresh reloads data for current month + 1 month before/after.
• Network connection required for refresh.

4. UNDERSTAND SHIFT INFORMATION
================================================================================

4.1 Shift Status Types
--------------------------------------------------------------------------------

Description: Each shift has a status that indicates its current state. The 
status is displayed as a colored badge in the shift card header.

[Figure 07 - Shift Status Badges]

Status Types:

1. In Coming (Scheduled)
   - Color: Orange/Yellow
   - Meaning: Shift is scheduled but hasn't started yet
   - Typical scenario: Future shifts or shifts starting later today
   - Actions: No action required, just be aware of the schedule

2. Completed
   - Color: Green
   - Meaning: Shift has been completed successfully
   - Typical scenario: Past shifts where you checked in and out
   - Check-in and check-out times will be displayed

3. Absent
   - Color: Red
   - Meaning: You were scheduled but did not attend
   - Typical scenario: Missed shifts without check-in
   - May require explanation or documentation

4. Cancelled
   - Color: Gray
   - Meaning: Shift was cancelled by management
   - Typical scenario: Shifts removed from schedule
   - No action required from employee

Notes:
• Status updates automatically based on check-in/out and time.
• Completed status appears after you check out.
• Absent status may appear if you don't check in by shift end time.
• Cancelled shifts may still appear in history.

--------------------------------------------------------------------------------

4.2 Shift Details Fields
--------------------------------------------------------------------------------

Description: Understanding what each field in the shift card represents helps 
you track your work hours and attendance accurately.

[Figure 08 - Shift Detail Fields]

Field Descriptions:

1. Shift Name/Title
   - Location: Top of card
   - Format: Text (e.g., "Morning Shift", "Shift #123")
   - Purpose: Identifies the specific shift assignment
   - May include shift type or schedule name

2. Scheduled Time
   - Icon: Clock
   - Format: "HH:MM - HH:MM" (e.g., "08:00 - 17:00")
   - Purpose: Shows your assigned work hours
   - This is your expected start and end time

3. Check In Time
   - Icon: Login arrow
   - Format: "HH:MM" (e.g., "08:05")
   - Purpose: Records when you actually started work
   - Compare with scheduled time to see if you were late

4. Check Out Time
   - Icon: Logout arrow
   - Format: "HH:MM" (e.g., "17:10")
   - Purpose: Records when you actually finished work
   - Compare with scheduled time to see if you left early/late

5. Overtime Hours
   - Icon: Timer
   - Format: "X.Xh" (e.g., "2.5h")
   - Purpose: Shows extra hours worked beyond scheduled time
   - Only appears if overtime was worked
   - May be compensated according to company policy

6. Break Hours
   - Icon: Coffee cup
   - Format: "X.Xh" (e.g., "1.0h")
   - Purpose: Shows total break time taken during shift
   - Breaks are typically unpaid time
   - Only appears if breaks were recorded

7. Late Minutes
   - Icon: Warning (amber)
   - Format: "Xmin" (e.g., "15min")
   - Color: Red text
   - Purpose: Shows how many minutes late you arrived
   - Calculated as: Check In Time - Scheduled Start Time
   - Only appears if you checked in after scheduled start

8. Early Leave Minutes
   - Icon: Warning (amber)
   - Format: "Xmin" (e.g., "10min")
   - Color: Red text
   - Purpose: Shows how many minutes early you left
   - Calculated as: Scheduled End Time - Check Out Time
   - Only appears if you checked out before scheduled end

9. Notes
   - Icon: Note/document
   - Format: Text (can be multiple lines)
   - Purpose: Additional information or comments about the shift
   - May include reasons for late arrival, early leave, or other notes
   - Added by you or management

Notes:
• All times use 24-hour format (HH:MM).
• Hours are displayed with one decimal place.
• Fields only appear when they have data.
• Empty shifts show minimal information.
